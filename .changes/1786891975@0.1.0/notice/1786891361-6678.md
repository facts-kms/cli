# Initial Release

Initial release of the Rust `fact` command-line interface for working with
Facts Protocol v0 ledgers from the terminal.

- Provides local ledger setup, switching, status inspection, and read-only
  ledger attachment.
- Manages signing identities, friendly actor aliases, capabilities, and ledger
  remotes.
- Creates, reviews, accepts, rejects, revises, withdraws, and archives
  propositions.
- Supports comments, invitations, tags, conflict discovery, and conflict
  resolution workflows.
- Includes proposition search, history, content import/export, sync, and
  JSON-friendly command output.
